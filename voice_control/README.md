# 语音指令控制

用阿里云百炼（DashScope）语音识别把口述指令转成 BPX 机器狗动作。程序复用
`dual_dog` 的配置、安全限幅和驱动接口，默认使用模拟模式，可切换到真实 BPX SDK。

## 安装

```powershell
py -3 -m pip install -r voice_requirements.txt
```

API Key 从环境变量 `DASHSCOPE_API_KEY` 读取，也可以放到本目录的 `.env`：

```text
DASHSCOPE_API_KEY=sk-your-api-key
```

仓库里已放好一个 `.env`，里面是你这次提供的百炼 Key。不要把 `.env` 提交到
任何公开仓库。

## 运行

### 控制界面内使用

启动原控制台后，选择目标并连接设备，切换到“语音控制”页签，点击“开始语音识别”
即可。录音结束后静音约 1.5 秒自动停止，识别文本和映射后的指令会显示在页签里。
前进/横移速度和旋转速度可在页签内调整；跑步、翻转、跳跃、双足、翻身等特技指令需要同时勾选
“允许特技语音指令”和特技动作页的安全确认。执行过程中可以点击“停止语音指令”
主动截止当前指令；复合指令（例如“全军列阵”）会按步骤依次执行，同样可整体截止。

```powershell
py -3 -m dual_dog
```

### 独立命令行

模拟模式（默认）：

```powershell
.\run_voice.ps1
```

也可以直接运行：

```powershell
py -3 -m voice_control
```

启动后程序会逐个尝试连接配置中的机器狗：连上的自动作为可用目标，连不上的会
跳过并显示“离线跳过”。随后按 Enter 开始录音，说话结束后静音约 1.5 秒会自动
停止，也可以再按一次 Enter 提前结束。每条命令默认执行 2 秒后停止。在提示符
直接输入文字（例如 `前进`）也可以当作指令，方便没有麦克风时调试。

常用参数：

```text
--driver bpx            使用真实 BPX SDK
--targets dog01,dog02   指定默认目标
--speed 0.4             设置前进/横移基础速度（m/s）
--yaw-speed 0.6         设置原地旋转基础速度（rad/s）
--allow-stunts          允许跑步、翻跳、跳跃、双足、翻身等特技
--confirm               每条指令执行前先确认
--once 指令.wav         识别一个本地音频文件后退出
--list-devices          列出录音设备索引
--device 1              使用指定录音设备
--single                只处理一条语音后退出
```

真机示例：

```powershell
py -3 -m voice_control --driver bpx --targets dog01 --speed 0.2 --confirm
```

## 支持的语音指令

目标机器狗可以在句子里说：`全部`、`一号` 到 `十号`、`dog01` 等。`全部` 只包含
启动时自动连上的在线机器狗；未指定目标时同样使用在线机器狗。

```text
站立 / 站起来 / 起立        站立
坐下 / 趴下 / 蹲下          趴下
走路 / 行走                 切换到 Walk 步态
前进 / 往前走               前进固定时长
直行 / 直走                 前进固定时长
后退 / 向后退               后退固定时长
左移 / 右移                   左移 / 右移
左转 / 右转                   原地旋转
停止 / 停下 / 别动           停止
急停 / 紧急停止 / 刹车       急停阻尼
跑步 / 快跑                 跑步（特技，默认关闭）
左翻 / 右翻                 侧翻（特技，默认关闭）
弹跳 / 跳跃                 跳跃（特技，默认关闭）
踱步 / 走马                 踱步（特技，默认关闭）
跳步                        跳步（特技，默认关闭）
双足正立 / 双足倒立          特技，默认关闭
原地跳 / 上跳               原地跳跃（特技，默认关闭）
前跳 / 向前跳               前跳（特技，默认关闭）
后跳 / 向后跳               后跳（特技，默认关闭）
左跳 / 向左跳               左跳（特技，默认关闭）
右跳 / 向右跳               右跳（特技，默认关闭）
翻身 / 翻身站起             翻身站起（特技，默认关闭）
```

可以附加秒数、距离或速度词，例如 `一号前进3秒`、`直行3米`、`快速前进`、
`二号慢速后退`。距离会按当前语音速度换算成移动时长，属于开环估算。

复合指令：

```text
全军列阵 / 全体列阵 / 全军集合   全体站立，然后全体前进 5 秒
```

## 安全说明

默认是 `sim` 模拟驱动，不会连接真机。使用 `--driver bpx` 前应确认场地、人员、
独立硬件急停都准备好。跑步、翻转、跳跃、双足、翻身等指令默认被拦截，必须显式加
`--allow-stunts`。前进、后退、横移、旋转都会在指定时长结束后自动停止，Ctrl+C
会向已连接设备发送急停。语音识别和软件急停都不能替代硬件急停。

## 实现说明

`recorder.py` 用 `sounddevice` 录制 16 kHz 单声道 WAV，并做简单的能量静音检测。
`asr.py` 调用 DashScope `paraformer-realtime-v2` 实时识别接口处理本地文件，避免
离线 `Transcription` 需要公网 URL/OSS 上传的步骤，更适合短语音指令。识别文本交给
`commands.py` 匹配中文指令，`robot.py` 通过现有 `dual_dog` 控制器提交动作，并保持
速度指令持续刷新直到设定时长。
